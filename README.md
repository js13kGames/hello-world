This is is an example entry to showcase some of the features you can use for your game's presentation.

## Explain your game and its controls

You can use [Markdown](//markdownguide.org/cheat-sheet) to format your description and make it easier to digest by players and judges alike. Make it clear, simple, and interesting. The more concise it is, the better the chances people actually read it.

![A tiny pixel explorer beneath the js13kGames logo](https://play.js13kgames.com/hello-world/.c.png)

### Controls

You can use some basic HTML (no, no inline CSS/JS) for things which Markdown doesn't handle on its own. For example: 

| Key | Action |
| --- | --- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> or arrow keys | Move |
| <kbd>Space</kbd> | Dash |
| <kbd>R</kbd> | Restart |

- **Headphones recommended** for the full chiptune experience.
- Built in plain JavaScript with *zero dependencies*.
